Mod format and submission notes

Fox Mod Portal uses a simple catalog and a simple submission packet. It keeps the structure readable and easy to update.

.tamod package

MyMod.tamod
          ├── manifest.json
          ├── preview.png
          └── content/
              ├── maps/
              ├── enemies/
              ├── weapons/
              └── assets/

Manifest example

{
            "id": "fox.urban-raid",
            "name": "Urban Raid",
            "version": "1.0.0",
            "author": "Fox",
            "type": "Map",
            "game": "Tactical Assault VR",
            "platform": ["Quest"],
            "description": "A CQB warehouse scenario."
          }

Submission packet

The submission form exports JSON. That packet can be stored, shared, or copied into your own review workflow.

  • Mod name
  • Creator name
  • Category
  • Version
  • Description
  • Download link

Catalog rules

  • Keep titles short and specific.
  • Document dependencies when you add them.
  • Use the same creator name every time.
  • Update the version number for each release.
