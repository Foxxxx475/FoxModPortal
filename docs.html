Build for Fox Mod Portal

Start with a portable manifest and keep the content format simple.

.tamod package

The portal uses a ZIP-based package convention with the .tamod extension. The exact in-game loading behavior depends on the future TAVR integration layer.

MyMod.tamod
├── manifest.json
├── preview.png
└── content/
    ├── maps/
    ├── enemies/
    ├── weapons/
    └── assets/

Manifest example

{
  "id": "fox.urban-raid",
  "name": "Urban Raid",
  "version": "1.0.0",
  "author": "Fox",
  "type": "Map",
  "game": "Tactical Assault VR",
  "platform": ["Quest"],
  "description": "A CQB warehouse scenario.",
  "license": "All rights reserved"
}

Creator guidance

  • Use a unique mod ID such as creator.mod-name.
  • Increment the version when publishing an update.
  • Keep previews free of private information.
  • Only upload content you are allowed to distribute.
  • Document known dependencies and compatibility.

Current v1 limitation

Fox Mod Portal v1 is the public catalog and creator workflow. It does not claim that TAVR currently accepts external content. Runtime integration is a separate technical project.
